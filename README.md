# 网络工程师职业生涯发展报告

个人职业规划报告，基于网络工程专业背景，涵盖自我认知、职业技能、行业分析、行动计划等内容。

## 目录结构

```
├── index.html              # 报告入口（GitHub Pages 首页）
├── career-report.html      # 报告原始文件
├── .nojekyll               # 禁用 Jekyll 处理（保留 _shared 目录）
├── assets/
│   └── charts.js           # ECharts 图表初始化
└── _shared/
    └── js/
        └── echarts.min.js   # ECharts 图表库
```

## 部署到 GitHub Pages

1. 在 GitHub 创建新仓库（如 `career-report`）
2. 将本目录所有文件推送到 `main` 分支
3. 进入仓库 Settings → Pages
4. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
5. 保存后几分钟即可通过 `https://<用户名>.github.io/career-report/` 访问

## 本地预览

直接用浏览器打开 `index.html` 即可。
